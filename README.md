# Operation Albatros 2026 Portal

Een kant-en-klare vakantieportal in overdreven geheime-operatie-stijl.

## Starten in VS Code

1. Open deze map in VS Code.
2. Open de terminal.
3. Installeer dependencies:

```bash
npm install
```

4. Start lokaal:

```bash
npm run dev
```

5. Open de link die Vite toont, meestal:

```bash
http://localhost:5173
```

## Login

Wachtwoord:

```txt
Albatros2026!
```

## Aanpassen

De belangrijkste content staat in:

```txt
src/main.jsx
```

Daar kun je reizigers, teksten, stats, route en bingo aanpassen.

De styling staat in:

```txt
src/styles.css
```

## Online zetten

De makkelijkste manier is via Vercel:

1. Maak een gratis account op Vercel.
2. Upload of koppel je project via GitHub.
3. Framework wordt automatisch herkend als Vite.
4. Deploy.

Let op: dit is een simpele front-end login. Voor familiegebruik is dat prima, maar het is geen echte beveiligde accountomgeving.
